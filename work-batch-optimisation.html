The engineering question.

Batch performance varies with operating conditions and process parameters. The project investigates how historical data can support more informed parameter choices while keeping the batch sequence and the operator’s role clear.

A practical approach.

A modular demonstration connects batch data, analysis and machine learning to parameter recommendations. The architecture uses ISA-88 concepts to place the analytics alongside an established batch structure.

Batch historyData analysisML modelRecommendation
  • Batch performance analysis and data preparation.
  • Machine learning models and parameter recommendations.
  • A modular architecture aligned conceptually with ISA-88.

What this project demonstrates.

A demonstration project. Live optimisation, PLC/SCADA integration, digital twin modelling and cloud deployment are listed as future improvements in the repository. No production yield improvement is claimed here.

The public repository is the source of truth for implementation details and current development status.
