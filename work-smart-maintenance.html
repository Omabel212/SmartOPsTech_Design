The engineering question.

A single threshold tells only part of an equipment’s story. The project explores patterns in operating data that can support maintenance planning and investigation.

A practical approach.

The published system uses Random Forest for predictive modelling and Isolation Forest for anomaly detection, with a structured workflow from equipment data through processing to maintenance insights.

Equipment dataPreparationPrediction + anomalyMaintenance insight
  • Random Forest predictive modelling.
  • Isolation Forest anomaly detection.
  • Equipment health monitoring and structured insight reporting.

What this project demonstrates.

A portfolio demonstration. The repository lists live dashboards, SCADA integration and automated alerts as future work. Predictions require validation against representative equipment data before operational use.

The public repository is the source of truth for implementation details and current development status.
